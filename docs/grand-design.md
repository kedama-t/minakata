# Minakata

- AIエージェントハーネスによる自動情報収集システム
- 名称は徹底したフィールドワークで粘菌や藻類の分野で業績を残した在野の研究者「南方熊楠」に由来

## プロダクトの目的

生成AIが発達・普及していく中、「情報収集」の重要性が高まっている。
特に組織において、情報収集と知識の平準化は円滑な活動に重要だが、調査とドキュメンテーションはそのための技術を要求する作業である。
そのため、組織としての情報収集をするにあたっても、個々人の興味関心やモチベーション、理解度、文章力によって収集された情報の粒度や品質にばらつきが生じてしまう。
また、時間的制約から情報収集にかけられる労力が個々人により異なる、その分野が好きな人に収集の負荷が偏ってしまうという問題もある。そして、当該分野に詳しい人が書いたドキュメントが、その他の人にわかりやすいとは限らない。

Minakataの目的は、エージェントハーネスを使って情報収集とドキュメント作成を自動化することにより、情報収集と取りまとめの労力を減らし、ドキュメントの粒度・品質を均一に保つことで、こうした問題を解決することである。

## プロダクトの方針

1. ユーザーの関心分野の情報収集を自動化するためにエージェントハーネスを利用する
2. 調査結果はフロントマター付きMarkdownドキュメントとして保存する。これは再利用性が高いことと、エージェントがGrepで参照しやすいという理由による
3. ユーザーはWebUIを通じてMarkdownドキュメントをWebページとして閲覧できる
4. ユーザーは直接ドキュメントを編集することはできない。権限を持つユーザーがエージェントに修正依頼を出すことで編集することで、記事の品質を一定に保つ目的がある
5. WebUIからの編集依頼や調査依頼はキューイングし、AIエージェントが順次処理する。
6. プロンプトインジェクションへの対策を厳重に施す
